Frequently Asked Questions

Everything you need to know about AgentGuard, local security, and payments.

Does AgentGuard send my code or prompts to the cloud?

No. AgentGuard is 100% local-first. When you run the CLI or evaluate agents, tests execute directly on your machine against your specified target. No test inputs, agent outputs, or proprietary system prompts leave your system.

Can I pay with M-Pesa?

Yes. By clicking the "Pay with M-Pesa / Card (Paystack)" button, Kenyan developers can pay KES 5,000 directly via M-Pesa STK push. Your license key is issued automatically within 2 seconds upon payment confirmation.

How is Polar.sh used for global USD payments?

Polar.sh acts as our Merchant of Record for international buyers paying via credit card, Apple Pay, Google Pay, or SEPA. It handles VAT/sales tax compliance and sends a webhook to our Cloudflare Worker to issue your license instantly.

Which AI frameworks and model providers are supported?

AgentGuard supports any Python or Node.js agent loop: LangChain, CrewAI, AutoGen, OpenMausBot, or custom raw API scripts calling OpenAI, Anthropic, Ollama, LM Studio, or DeepSeek.

How do I use my Pro license in CI/CD?

Simply set the AGENTGUARD_LICENSE_KEY repository secret in your GitHub Action workflow. The CLI verifies the key during the run and unlocks all 150 adversarial cases and export badges.

What is the difference between SOUL.md and tool-gate interceptors?

SOUL.md establishes the non-negotiable cognitive identity and refusal rules for the LLM. The tool-gate interceptor is code that wraps around actual tool functions (like shell execution or financial transfers) to block malicious calls deterministically even if the model is tricked.
